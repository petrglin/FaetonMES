# Структура сайта Faeton MES

Главное меню: Главная → Возможности MES/ERP → Типовые решения → Референции → Внедрение → Команда → Контакты.

## Типовые решения

Согласовано с пользователем: раздел показывает комбинации функций Faeton MES для определённой отрасли, типа предприятия или задачи. Примеры: типовое решение для кухонного предприятия; типовое решение для производителя жилой мебели.

«Возможности» описывает отдельные функции, «Типовые решения» — их сочетания и совместное применение. Конкретный состав решений ещё не определён. К проработке раздела вернёмся позже.

Сейчас добавлено только главное меню и пустые страницы разделов. Дизайн, подменю и подробное содержание ожидают описания и референсов пользователя.

## Предварительное оформление

Добавлен предоставленный пользователем логотип в public/brand/faeton-logo.png без изменений. Палитра по референсу: синий #0059BD, стальной #8593A3, светлый фон #F4F7FA. Цвета предварительные; точные брендовые значения ещё не предоставлены. Общие цвета хранятся в CSS-переменных src/app/globals.css. Главная содержит временный вводный блок, разделы остаются заглушками.

## Модули MES/ERP

Три программных направления временно убраны с главной по просьбе пользователя. Вместо них на главной и в разделе «Возможности MES/ERP» размещены одинаковые 16 модулей, в согласованном порядке. URL раздела остался /features.

Названия, изображения и будущие описания находятся в src/lib/modules.ts. Чтобы добавить 3–4 предложения под названием, заполните поле description соответствующего модуля: текст появится в компактном поле на обеих страницах. Пустое поле остаётся визуально свободным и скрыто от скринридера. Интерфейс управления содержимым пока не создан.

Иллюстрации: public/modules/*.svg. Для каждого модуля создана отдельная векторная иллюстрация в сине-стальной палитре с мотивом дуги из логотипа.

По последующей просьбе пользователя поля описаний уменьшены: минимальная высота 100px, внутренний отступ 12px. Фиксированная высота названий убрана; отступ до описания — 10px. Поле расширяется при добавлении текста.

На широких экранах (от 1280px) модули размещаются по пять в ряд. Нумерация убрана. Иллюстрации уменьшены до 50% ширины блока и выровнены по центру.

Заголовок главной: «MES система для управления мебельным предприятием». Надпись «Модули системы» убрана с обеих страниц. Во всех описаниях пока общий текст: «описание модуля или функциональности системы Faeton MES». Названия карточек уменьшены до 17px с весом 500. При наведении иконка плавно покачивается и приподнимается; анимация отключается при prefers-reduced-motion.

Первый блок главной уменьшен примерно вдвое по высоте: логотип 230px вместо 460px, заголовок до 32px, отступ сверху 45px вместо 90px, сокращены внутренние отступы. Кнопки сохраняют удобную высоту 44px.

Под заголовком главной размещён текст пользователя о Faeton MES (включая упоминание 2020 Insight) и шесть преимуществ. Две кнопки первого блока убраны. Тексты хранятся в src/lib/home-content.ts.

Удалён вводный абзац «Никто не знает ваш бизнес лучше вас… 2020 Insight…». Остальной текст сохранён: уменьшены интервалы и межстрочное расстояние, расширена колонка текста, преимущества оформлены компактными блоками с синим акцентом.

## Футер

Общий футер на всех страницах: логотип и краткое описание, группы ссылок «Продукт» и «Компания», переход к контактам, копирайт и ссылка наверх. Адаптивная сетка и тёмно-синий фон. Структурные ориентиры: актуальные футеры linear.app и vercel.com. Реквизиты, соцсети и юридические документы добавим после получения данных.

## Запрос демо

Кнопки у заголовка главной и в футере открывают общий диалог Base UI с полями: имя, компания, телефон, email. Фокус ограничен окном и возвращается к исходной кнопке; Escape и клик вне окна закрывают форму. Это пока макет без отправки данных, сохранения и backend; в форме есть явное уведомление. CSS-анимации по официальному Animate Эмиля Ковальски: нажатие 160ms, окно и фон 250ms, scale(.96) и opacity, reduced motion. Скилл установлен локально в .agents/skills/animate (будет доступен агенту в следующих запросах к проекту).

## Лаборатория Thinking Orbs

Отдельная страница `/examples/thinking-orbs` демонстрирует пакет `thinking-orbs` (Jakub Antalik): девять состояний, паузу, скорость, светлую и тёмную тему. Три сценария FaetonMES показывают помощника, расчёт плана и обмен данными с ERP. Сценарии — локальные демонстрации, без backend и настоящего AI. Страница доступна по прямой ссылке; утверждённое главное меню не изменено.

## Бизнес-процесс

На главной справа от заголовка «Возможности MES/ERP» добавлена кликабельная надпись «Бизнес-процесс». Она открывает доступное диалоговое окно-заготовку для будущей инфографики, с закрытием по Escape, крестиком и возвращением фокуса на кнопку.
